# Product Direction

## Core problem

Marketplace search is abundant; trustworthy opportunity discovery is scarce. Market Radar should reduce a large stream of listings to a small set of opportunities worth investigating.

## MVP outcome

Given a search intent and location, return ranked listings with:

- asking price
- estimated fair value
- expected spread after configurable costs
- confidence
- risk band
- reasons supporting the score

## Guardrails

The initial product is read-only. It does not automatically message sellers, purchase goods, or create listings.

## Roadmap

1. Provider-neutral core and deterministic scoring.
2. Facebook read-only connector.
3. Historical comparable store and price history.
4. Risk signals and richer cost model.
5. Persistent monitors and alerts.
6. MCP/API delivery.
7. Optional human-approved action workflows.
